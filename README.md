# Halloween Bash Invite

## RSVP email notifications

RSVP submissions are sent to the email address configured in the FormSubmit URL
in `index.html`. The email includes the guest's name, attendance choice, costume,
and required potluck contribution.

To enable notifications:

1. Publish the page, then submit a test RSVP.
2. Check the configured inbox (including spam) for FormSubmit's activation
   email and follow its confirmation link. FormSubmit requires this one-time
   confirmation before it can deliver submissions.
3. Submit another test RSVP and confirm the email arrives.

If you want notifications sent to a different inbox, replace the email address
in the FormSubmit URL in `index.html` with that inbox before publishing.
